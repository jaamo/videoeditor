# videoeditor

A collection of video editors. Each folder is an isolated, standalone project with
its own dependencies, README and tooling — `cd` into one and work from there.

| Editor | What it does |
| --- | --- |
| [`outerview-screencast/`](outerview-screencast/) | Edit screen recordings into vertical Outerview product videos (Remotion, Kdenlive, Whisper, agent workflow). |
